QUICK NOTE ON v3.5.4 - CRX SIGNATURE VERIFIED
---------------------------------------------
v3.5.3 fixed the last layout bug (status bar always visible) but its
.crx shipped with a STALE signature - the CRX3 header was signed over
an older zip than the archive actually inside, so Chrome rejected it
with "CRX signature verification failed" while the 3.5.2 crx kept
working.

THE FIX IN v3.5.4: every CRX is repacked fresh from the extension
source with the SAME stable release key - the extension ID is
UNCHANGED (likldbkamojokkfdlcjibiljpgbbnohc), so pairing, settings and
the hub auto-update chain all survive. tool/crx3.py verify (a
Chrome-identical signature check) is now a HARD BUILD GATE: a CRX
whose signature does not match the archive inside can never ship
again. All artifacts (CRX, extension zip, DEB, Setup EXE) are rebuilt
and their SHA256 checksums are in docs/SHA256SUMS-3.5.4.txt - check
before installing:

  Windows CMD        : certutil -hashfile AdvPrint-Pro.crx SHA256
  Windows PowerShell : Get-FileHash AdvPrint-Pro.crx -Algorithm SHA256
  Linux / macOS      : sha256sum AdvPrint-Pro.crx

EVERYTHING ELSE IS THE WORKING v3.5.3 BUILD: the always-visible status
bar, the real success rate, no more save-password prompts, date+time
everywhere, the history per-row View file button and date filter, the
live dashboard cards, the ProTheme theme engine (8 themes + density /
corners / frame) and the single port for every queue.

WHAT v3.5.2 ALREADY FIXED (kept unchanged here)
-----------------------------------------------
1) REAL SUCCESS RATE - success = printed + saved (a saved file IS a
   delivered document); failed = failed + dead; canceled jobs stay
   out of the math; the tile shows "7d N ok / M fail" plus a hover
   tooltip with the full breakdown - live from your job database.
2) NO MORE "SAVE PASSWORD?" PROMPTS - token boxes are CSS-masked text
   inputs and every input is autocomplete=off.
3) DATE + TIME EVERYWHERE - history, dashboard, audit, LAN visitors,
   DropZone and debug rows all show "YYYY-MM-DD HH:MM:SS".
4) HISTORY: VIEW FILE + DATE FILTER - per-row View button opens the
   stored file inline (/jobs/<id>/file?view=1); From/To date filter
   queries the WHOLE job database server-side.

UPGRADE IN 3 STEPS (from any v3.x)
----------------------------------
1. Close the old hub (tray icon -> Exit) and run the new
   AdvPrint-Pro-Setup-3.5.4.exe - it installs over the old folder and
   keeps config.json, the queue database and your rules.
2. Start AdvPrint Pro. The tray tooltip shows "v3.5.4 - running on
   http://127.0.0.1:9235".
3. Chrome updates the extension by itself from the hub within a minute
   (chrome://extensions -> AdvPrint Pro -> 3.5.4). Linux .deb: sudo
   dpkg -i advprint-pro_3.5.4_all.deb.
   Drag-install instead? Use the included AdvPrint-Pro.crx ( Developer
   mode ON at chrome://extensions ) - its signature is build-verified.
