QUICK NOTE ON v3.5.3 - STATUS BAR ALWAYS VISIBLE
------------------------------------------------
v3.5.2 was confirmed working; one last layout bug remained: the bottom
status bar (Hub Running / IP:port / Printers / Queue / History / LAN /
DropZone / Uptime / version) rendered BELOW the bottom edge of the
window - "outside bottom, not showing". Root cause: the stylesheet
never reset the browser's default 8px body margin and never set
box-sizing, so the desktop frame (height:100vh + 14px padding + 8px
margin) was 936px tall inside a 900px window; body{overflow:hidden}
clipped the overflow and the status bar - the last element in the
window - went hidden.

THE FIX IS THREE DECLARATIONS: body{margin:0} plus
box-sizing:border-box on the desktop and window layers, so 100vh is
the REAL height. The bar now sits fully on screen at every window
size (verified by a rendered-browser probe at 720p / 768p / 900p /
1000p, zero JS errors).

EVERYTHING ELSE IS THE WORKING v3.5.2 BUILD: the real success rate,
no more save-password prompts, date+time everywhere, the history
per-row View file button and date filter, the live dashboard cards,
the ProTheme theme engine (8 themes + density / corners / frame) and
the single port for every queue.

UPGRADE IN 3 STEPS (from any v3.x)
----------------------------------
1. Close the old hub (tray icon -> Exit) and run the new
   AdvPrint-Pro-Setup-3.5.3.exe - it installs over the old folder and
   keeps config.json, the queue database and your rules.
2. Start AdvPrint Pro. The tray tooltip shows "v3.5.3 - running on
   http://127.0.0.1:9235".
3. Chrome updates the extension by itself from the hub within a minute
   (chrome://extensions -> AdvPrint Pro -> 3.5.3). Linux .deb: sudo
   dpkg -i advprint-pro_3.5.3_all.deb.
