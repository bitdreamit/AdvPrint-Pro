QUICK NOTE ON v3.4.8 - RULES TABLE FITS (layout-only release)
--------------------------------------------------------------
The FIRST v3.4.8 attempt bundled the table fix with extra logic
changes and did not work - per the user's request it was fully
REVERTED to the working v3.4.7 tree. THIS release is v3.4.7 plus
EXACTLY ONE change, and it is CSS/layout only - no print, rule,
queue or network logic was touched:

1) THE ONE UI RULES TABLE FITS ITS CARD AGAIN. With Paper or another
   extra column showing, the nowrap headers forced ~1145px inside a
   ~990px card and pushed the Runs column + the Edit/Del buttons
   OUTSIDE the card border. Fixed at the root:
   - headers may wrap to a second line;
   - every ONE UI table sits in an inner scroll container
     (.tbl-wrap) - on very narrow windows the table scrolls INSIDE
     the card, the page never scrolls sideways, the card border is
     never crossed;
   - the rules table is compact: at the normal console width (1280px)
     all 14 columns incl. Edit/Del fit WITHOUT any scrolling;
   - long "Page content" cells ellipsis-clamp like the URL cells.
   Measured on the live hub + screenshots: scripts/ui_check_v348.py.

2) EVERYTHING ELSE = THE WORKING v3.4.7. Configurable hub port (9235
   default, movable when busy), DropZone watch Enable/Disable toggle,
   strict LAN share with the IP hit list + one-click Allow, URL rules
   that really match (glob / regex / contains + the "Which rule
   fires?" test box), one TCP port 9235 for every queue, the popup
   that remembers the last printer, manual LAN/IPP re-scan, auto-CRX
   on install, idempotent set-default.

UPGRADE IN 3 STEPS (from any v3.x)
----------------------------------
1. Close the old hub (tray icon -> Exit) and run the new
   AdvPrint-Pro-Setup-3.4.8.exe - it installs over the old folder and
   keeps config.json, the queue database and your rules.
2. Start AdvPrint Pro. The tray tooltip shows "v3.4.8 - running on
   http://127.0.0.1:9235".
3. Chrome updates the extension by itself from the hub within a minute
   (chrome://extensions -> AdvPrint Pro -> 3.4.8). Linux .deb: sudo
   dpkg -i advprint-pro_3.4.8_all.deb.
