QUICK NOTE ON v3.3.0 - THE ANY-PC INVITE + DUAL-STACK LISTENER RELEASE
--------------------------------------------------------------------
1) THE INVITE LINK CONNECTS THE RIGHT PC NOW. Opening
   http://<hub-ip>:9235/connect?t=<token> no longer points at the
   serving PC's own lan_ip() guess - the page uses the address YOU
   typed (and saves exactly that peer URL). Opening the invite ON the
   hub PC itself shows an explainer page instead of adding the hub to
   itself, POST /peer-connect refuses self-invites, the page probes
   the visiting PC's own hub before you click, and a token that
   belongs to a DIFFERENT PC's hub is explained in plain words.
2) EVERY LISTENER ANSWERS IPv4 AND IPv6 ON EVERY INTERFACE. The 9235
   LAN hub, the 631 IPP mirror and the RAW 9100 port bind one socket
   per interface IP plus one [::] socket each - a VPN/second-NIC PC no
   longer goes deaf on its other addresses, and IPv6-only LANs work.
   The LAN panel shows the REAL bound sockets (Hub addresses chips,
   RAW + 631 rows), and interface changes rebind automatically.
   allowed_ips still gates every socket exactly as before.
3) PER-PRINTER IPP QUEUES WORK FOR ANY PRINTER THAT EXISTS. Unicode
   printer names (Bangla / Arabic / CJK) get their own distinct,
   percent-encoded queue slugs; matching tolerates dash / underscore /
   %20 styles; a newly added printer's queue goes live in seconds; the
   unknown-queue 404 lists the queues that ARE live; mDNS announces up
   to 24 per-printer queues (+ the AAAA record for IPv6).
4) IMPORTANT UPGRADE STEP: the extension is auto-updated FROM THE HUB
   (updates.xml) - after updating the hub, check
   http://127.0.0.1:9235/extension/info : it must show
   "stale": false and version 3.3.0. If it shows "stale": true, re-run
   the installer (or restart the hub once) - the embedded CRX was not
   synced; Chrome then silently updates the extension to 3.3.0.

UPGRADE IN 3 STEPS (from any v3.x)
----------------------------------
1. Close the old hub (tray icon -> Exit) and run the new
   AdvPrint-Pro-Setup-3.3.0.exe - it installs over the old folder and
   keeps config.json, the queue database and your rules.
2. Start AdvPrint Pro. The tray tooltip shows "v3.3.0 - running on
   http://127.0.0.1:9235".
3. Chrome updates the extension by itself from the hub within a minute
   (chrome://extensions -> AdvPrint Pro -> 3.3.0). Linux .deb: sudo
   dpkg -i advprint-pro_3.3.0_all.deb.

QUICK VERIFY (2 minutes)
------------------------
- Console: http://127.0.0.1:9235/ui - LAN Sharing card shows "Hub
  addresses" chips (IPv4 AND IPv6 where available), the RAW row shows
  every bound 9100 socket.
- Invite: LAN card -> "Connect another PC" -> Copy invite link -> open
  it on the OTHER PC. The page says which PC's hub it adds and probes
  that PC's own hub first. Open it on the hub PC itself and you get
  the "this invite is for the OTHER PC" explainer - never a self-add.
- Per-printer queues: http://127.0.0.1:9235/printers lists
  ipp://<ip>:9235/ipp/print/<printer> for EVERY printer, Unicode
  names included. Add one on another PC - it connects first try.
- IPv6: on an IPv6-capable PC, netstat -ano | findstr ":9100" shows
  0.0.0.0/your-IPv4 AND [::] rows - both answer.
