QUICK NOTE ON v3.5.1 - DASHBOARD LIVE DATA (dashboard-only bug fix)
-------------------------------------------------------------------
The user reported: "in all previous versions dashboard data so fake -
it always shows 33.3% success and the default printer and other things,
this is not dynamic." Correct - the dashboard LOOKED live but several
values were static demo markup that no code ever replaced. v3.5.1 is a
DASHBOARD-ONLY bug fix on the working v3.5.0 (ProTheme) tree - no
print, rule, queue, theme or network logic was touched:

1) PRINT HUB STATUS CARD - every row is now REAL (3 s refresh):
   - uptime     ticks from the actual hub start time (was stuck at
                the static "uptime 04:12:37" forever);
   - Service    HEALTHY while the real print worker thread is alive,
                DEGRADED otherwise (was hardcoded HEALTHY);
   - Listen     the address this browser actually reached;
   - LAN share  real share_lan config + your PC's real LAN URL;
   - IPP        real ipp_printer config (READY / OFF) - also fixes
                the bug where the row was overwritten by the mDNS
                text ("printers announce themselves");
   - RAW port   the REAL JetDirect socket state (raw_active +
                raw_printer_port + the actual bound address);
   - DropZone   real watch state + the REAL number of PDFs waiting;
   - Connections real counts: this PC (+ saved LAN PC) and
                online/total peers from /peers (was always "2 PCs
                2 peers");
   - Token      the REAL hub token, masked to first...last 4.
   The dashboard subtitle now shows your real PC name (was always
   "AI-Lab").

2) DEFAULT PRINTER CARD - shows the REAL OS default printer with its
   LIVE state: name from the hub, status chip READY / OFFLINE /
   PAPER OUT / ERROR from the printer scan, and the real status-hold
   setting. (Was hardcoded "HP Laser 103 107 108 / OFFLINE / status
   hold ON" in every previous version.)

3) RECENT JOBS CARD - the caption now counts TODAY'S REAL jobs
   ("last 6 of N today"), the rows were already live.

4) KPI ROW - was already live and stays live: jobs today, 7-day
   success rate computed from the job database, queue size, printers
   ready, hub version.

5) THEME ENGINE (from v3.5.0, unchanged): 8 themes (Cobalt, Classic
   IDM, Emerald, Violet, Graphite, Midnight, Carbon, System) +
   density / corners / window frame in Settings > Appearance, saved
   per browser, applies instantly.

UPGRADE IN 3 STEPS (from any v3.x)
----------------------------------
1. Close the old hub (tray icon -> Exit) and run the new
   AdvPrint-Pro-Setup-3.5.1.exe - it installs over the old folder and
   keeps config.json, the queue database and your rules.
2. Start AdvPrint Pro. The tray tooltip shows "v3.5.1 - running on
   http://127.0.0.1:9235".
3. Chrome updates the extension by itself from the hub within a minute
   (chrome://extensions -> AdvPrint Pro -> 3.5.1). Linux .deb: sudo
   dpkg -i advprint-pro_3.5.1_all.deb.
