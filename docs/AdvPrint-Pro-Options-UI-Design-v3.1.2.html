General

power switches + browser behavior · plain English, one switch each
⚡ Power switches every silent / background behavior — one switch each
AdvPrint enabled (master switch)

OFF = the extension stops completely: no printing, no auto-print, no window.print() hook, no page API, no context menu. A gray OFF badge shows on the toolbar icon.

Queue mode (jobs wait in order)

ON = every job goes through the hub queue in order (Pause/Resume works, big jobs line up). OFF = instant print. If no printer is active the job is auto-queued instead of failing.

Auto-print rules (silent background printing)

The power switch for every rule in the Rules tab. OFF (paused) = NO rule auto-prints; manual prints keep working.

Intercept window.print() (web app prints go silent)

Web apps (Odoo, POS, dashboards) that call window.print() print silently through the hub instead of opening the dialog. Also intercepts Ctrl+P / Cmd+P.

Debug mode — find problems fast

ON = the extension reports every error to the hub and the hub logs verbosely. Open the Debug tab to see WHEN / WHY / WHERE printing fails.

Retry when the hub comes back

If the hub is offline, jobs are kept in the browser and sent automatically as soon as the hub answers again (checked every minute).

UI language

English or বাংলা for the popup and this Options page. "Automatic" follows the browser language.

🌐 Browser behavior what happens around the printing
Print every PDF opened in the browser (simple mode)

ANY PDF you open is printed silently and its tab closes. No dialog, no rules needed.

Close tab after auto-print (default OFF)

ON: when a rule auto-prints an opened URL, the tab closes right after the job is queued — zero browser view, the paper just comes out.

When a page print call fails

Controls the automatic fallback of printPdfLink() / printPdf(): open the URL in a normal tab so the browser prints it the default way, or stay completely silent.

Right-click menu

Adds "AdvPrint Pro" to the right-click menu: print page / print selection / print linked PDF / print screenshot.

Toolbar badge (green OK / red !)

Shows OK or ! on the extension icon for a few seconds after every job.
