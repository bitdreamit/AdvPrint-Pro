Rules are stored on THIS hub and pushed to the browser extension automatically (the extension adopts hub rules when it has no local edits — local edits always win and are pushed back here). One rule = one line in the extension’s rule engine.
🔒 Website whitelist which sites may drive AdvPrint from a page
—  Default is * — ALL websites are allowed to print through AdvPrint Pro out of the box. To restrict, open the extension Options → Connections → Website API permission and replace * with one pattern per line, e.g. *://www.htncr.org/*. The extension reports its live list here.

Power Switches

every switch of the hub in one panel
Pause queue

Holds every new job. Resume releases them in order. Same as the toolbar Pause button.

LAN sharing

Listen on all interfaces so other PCs / phones can print through this hub (token required).

IPP printer

Expose the hub as an IPP network printer at /ipp/print (Windows 10/11, macOS, iOS, Android).

mDNS announce

Printers announce themselves — queues appear in Windows / iPhone printer lists by themselves.

Hold jobs while printer offline

Jobs wait instead of failing when the printer is offline.

Instant fallback

Queue OFF = print each job immediately (no FIFO waiting in line).

Keep printed files

Store every printed document so History → Reprint always works.

Watch a folder and print every file that lands in it.

🛤 Silent install — force-install by policy (NO Chrome Web Store)
Paste one line per browser into the matching registry key. The extension then installs on EVERY PC automatically and the “not listed in the Chrome Web Store” warning disappears — policy-installed CRXs are trusted. Works on Chrome, Edge, Brave, Chromium, Vivaldi (and any Chromium browser — same key, its own path). The policy value is prefilled below — Copy policy value above.
ChromeHKEY_LOCAL_MACHINE\SOFTWARE\Google\Chrome\ExtensionInstallForcelist
EdgeHKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Edge\ExtensionInstallForcelist
BraveHKEY_LOCAL_MACHINE\SOFTWARE\BraveSoftware\Brave-Browser\ExtensionInstallForcelist
ChromiumHKEY_LOCAL_MACHINE\SOFTWARE\Chromium\ExtensionInstallForcelist
VivaldiHKEY_LOCAL_MACHINE\SOFTWARE\Vivaldi\ExtensionInstallForcelist
Value name1  (2, 3… for more browsers/PCs)
Value—
⚠ Drag-and-drop installs (“developer mode”) show the sideload warning on every start. Policy force-install is the fix: it is silent, works on all Chromium browsers and never shows the warning. Per-user install uses HKEY_CURRENT_USER\… with the same path.
